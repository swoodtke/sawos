## Description

**A case that parks a launcher on a Timer to let a child run now depends on host time.** Found when SO-120.p1's server gate failed `process_reclaim` on riscv32 (it passes alone on the patch's tree and on main, 15 of 15 each, here and on the reviewer's machine).

**Why, by reading.** `process_reclaim`'s root starts its child, arms a Timer `PARK_NS` (20 ms) out, attaches it, and waits, relying on the wait to park root so the child runs and dies first. `CLAUDE.md` states this idiom as safe: "a case that parks a launcher on a Timer to let a child run orders them by scheduling, not by the clock". That was true while a Timer became ready only when its interrupt was serviced. Since SO-83 (merged `0b6652a8`), a wait first brings a Timer up to the clock: if the host stalls longer than the Timer's delay between the arm and the wait, the Timer is already expired at the wait, the wait answers at once, root never parks, and the child has not run. The failed run shows exactly that: `SOS reclaim: started`, then `body_back_while_held=0 (no room for what was asked)` with no fault line between.

**What is built.**
- Every case that parks on a Timer to let another process or thread run first is found (the runner's cases and their packages; search for a Timer armed and then waited on before an assertion about what the other side did), and each waits instead on an observable that says the other side did it: the child's death (a `Process` attached to the Waiter), an Event the other side signals, or a count the kernel keeps. The Timer stays only where the case is about the Timer.
- `CLAUDE.md`'s sentence is corrected: a wait now answers at once for a Timer whose expiry has passed, so parking on a Timer orders nothing under a stalled host.
- Each changed case is shown red under construction where one can be made (for example a Timer armed with a delay of zero, which is expired at the wait), and green after.

**Acceptance**
- [ ] the list of cases found, each with what it now waits on
- [ ] `CLAUDE.md`'s rule corrected
- [ ] the gate green
