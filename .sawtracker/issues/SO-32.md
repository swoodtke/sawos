# Docs unit 8: the HAL `ABI.md`s and READMEs, `README.md`, `CLAUDE.md` (epic SO-24)

You are cleaning history out of the sawos repository's markdown documentation
(everything except `spec.md`, which a parallel unit rewrites, and `designs/`,
which is the history archive and stays as it is). The lead wrote this brief.
**If it is wrong, contradicts what you find, or leaves a decision you can't
make from it, STOP and end your turn with a message beginning
`CLARIFICATION REQUEST:` and the exact question.**

## Scope

- In scope: `hal/arm64/kernel/ABI.md`, `hal/arm64/user/ABI.md`,
  `hal/riscv32/kernel/ABI.md`, `hal/riscv32/user/ABI.md`,
  `hal/riscv32-esp32c3/ABI.md`, `hal/riscv32-common/README.md`,
  `hal/riscv32-flat/README.md`, `hal/riscv32-esp32c3/README.md`,
  `README.md`, `CLAUDE.md`.
- Out of scope: `spec.md`, `designs/` (all of it), `.sawtracker/`, and every
  non-markdown file. Parallel units are editing code comments under `hal/`
  and elsewhere right now; don't touch them.

## Rules

The same rule as the code-comment units. Read
`/private/tmp/claude-501/-Users-shawn-Projects-sawos/5d6020df-836c-40ce-9e68-9362e1dabb2a/scratchpad/brief-comments-common.md`,
"The rules" section. In markdown terms:

- Remove design, unit, milestone and issue references used as provenance;
  dates; "used to / now / landed / re-ruled" narration; rejected
  alternatives (unless one would tempt a future editor into breaking
  something); and ALL-CAPS emphasis.
- Keep, exactly: register assignments, frame and record layouts, offsets,
  sizes, alignment, symbol names, section names, linker-script contracts,
  memory maps, the boot sequence, which side (kernel, HAL, user stub) owns
  what, and every rule a port to a new board must follow. **These files are
  ABI contracts. A wrong offset is a bug.** Where a doc states a value that
  the code beside it defines (a `.ld` symbol, a frame offset in `boot.S`,
  `trap.S` or a `lib.saw` constant), check it. Report any mismatch and leave
  the doc's value as it is.
- `spec.md §N` pointers stay.
- **Headings may be cited.** Before renaming or removing any heading, grep
  the tree (`git grep -n '<heading text>'`) for references to it. Keep any
  heading that something cites.
- Prose wraps at 80 columns. Tables and code blocks are exempt.

## `CLAUDE.md` is instructions, so handle it differently

`CLAUDE.md` tells every agent working in this repository how to behave.
**Do not change any instruction, rule or ruling's meaning.**
- Drop dates and design or issue provenance ("(user, Aug 31)", "sawlang#238
  D-b", "design 35 §7a's correction…", "fixed by M5 unit 8"), but keep the
  words "user ruling" where a rule is the user's, because that signals its
  authority.
- Keep the gate numbers (382 = 129 + 129 + 124) and the timing-dependent-case
  list exactly.
- The "Design records" section is about the history archive itself. Its
  instructions for citing designs stay.
- **Report, don't fix,** any instruction that has gone stale. For example:
  "The open work tracker is `designs/todo.md`" (the tracker is now
  sawtracker); "Every change gates on `make sos-test` before commit" versus
  the targeted-tests ruling; the GitHub Actions references. The lead will
  take those to the user.

Requested changes on patch SO-32.p1 (revision 2)

**Air: SO-32.p1 r2, changes requested.**

The volatile-facts pass is good, and the dropped hex constants and spans are benign:
- **The C3 self-relocating flash stub:** the old text called it unbuilt ("no stub in the build at all").
- **The `sos_pmp_*`/`syscall_return_pair` names:** they no longer exist in the code.
- **The new arm64 per-process-set and linear-map description** matches `build_set`/`linmap_build`.

But these are ABI documents, and several statements are false against the code. Some are new in this revision, and some are old errors restated. Three read-only reviewers covered all ten files; I re-checked the items marked ✓.

**1. Wrong:**
- **`hal/arm64/kernel/ABI.md:20-23` ✓:** "setting its countdown are instructions … the period arithmetic". `sink.c` says the down-counter (`cntp_tval_el0`) "is gone". The leaves are `freq`/`ctl_read`/`ctl_write`/`count`/`set_compare` (`cntp_cval_el0`), and the Saw side is nanosecond deadline arithmetic. Lines 97 and 276-278 of this doc already say so.
- **`hal/riscv32/user/ABI.md:28` ✓ (new):** "`sos_set_system_handle`, `sos_rt_write` and `sos_rt_abort`". `sos_set_system_handle` doesn't exist anywhere in the code. The handle is parked by sysapi's package-private `park_system_handle`.
- **`hal/arm64/kernel/ABI.md:103-107`:** `sos_kernel_fault`'s `put_str`/`put_hex` and `sos_prot_reset`/`sos_prot_region`, now stated as present-tense Saw, are named `report_str`/`report_hex` and `prot_reset`/`prot_region` in `lib.saw`. `sos_page_tables_build` is called from `boot.S`, not C.
- **`hal/arm64/user/ABI.md:3-4` and `hal/riscv32/user/ABI.md:3, 5, 181`:** "one symbol" and "one C file holding one function". Each `syscall.c` defines `sos_syscall1` and `sos_syscall3`, and each doc's own table lists both. riscv32 :4-5's "only the manifest's `[sos] native` line changing" is also wrong: root's `[sos.<triple>]` sections differ in `linker-script` too.
- **`hal/riscv32/user/ABI.md:105-106`:** "writing the four fields it sets". riscv32's `frame_init` writes three (mepc, sp, a0); four is arm64's.
- **`hal/riscv32/kernel/ABI.md:27-28` (new):** "The one interrupt function, `sos_mie_write`". `sink.c` also defines `sos_wait_for_irq`, which this doc's own tables list.
- **`hal/riscv32-flat/README.md:110-119`:** the exclusion table has four cases. The runner excludes five on flat: `stats_region_ro` is `TIER_ISOLATED`. Lines 66 and 94 name `PROT_ISOLATED`/`PROT_REPLAY_AT_SWITCH` constants, but the seam is the functions `prot_isolated()`/`prot_replay_at_switch()`.
- **`hal/arm64/kernel/ABI.md:250-252`:** "The tables are built before the MMU comes on". The real tables are built with translation on (`lib.saw`: "IT RUNS WITH THE MMU ALREADY ON"; `boot.S`). Only `_boot_l1` is written with it off.
- **`hal/arm64/kernel/ABI.md:46-48`:** "three functions", but `USER_IMAGE_BASE` is a static, and arm64-only.
- **`hal/riscv32-esp32c3/ABI.md:472-474`:** "`PROT_DOMAIN_SLOTS`, a board number that sizes the domain pool". It's rv32core's, shared by every riscv32 profile, and riscv32 has no domain pool. The old text recorded this as a filed finding.
- **`hal/riscv32/user/ABI.md:178-179`:** "the register names and the `ecall` instruction, which are the whole of this directory's contract". The directory holds only the linker scripts; the stub is in `riscv32-common/user/syscall.c`.

**2. Meaning shifted, or a fact lost:**
- **`hal/riscv32/user/ABI.md:153-163`:** "A driver can instead declare the window in its own manifest" now offers a live alternative. The loader accepts a declared window only for root (`validate_image(…, true)` vs children's `false`), and spec §2.5 calls the path dormant.
