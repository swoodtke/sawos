**Networking A3-3: the riscv32 and flat virtio board rows, `tools/netpeer`, the runner's network path, and a probe case.**

The design is `SO:virtio-net` revision 4, §2.3 and §6.3 to §6.5, with the owner's rulings of Nov 25: the peer is written in Saw, one per case, and QEMU starts paused until the stream connects. This unit is §8's A3-3. It covers riscv32 and flat only; arm64's rows come with K2.

<!-- sawtracker:comment {"author":"agent:claude-sawos","body_bytes":1830,"created":"1795648485","id":"c3"} -->
**Lead: SO-164.p1 is A3-3.** One commit on current main.

**What it adds:**
- **Board rows.** `VIRTIO0` to `VIRTIO7` (`virtio-mmio`, base `0x1000_1000` + N×0x1000, len 0x1000, line N+1) in the riscv32 and flat board files. `sosimage board` and `check-tree` read them clean.
- **`tools/netpeer`**, a hosted Saw package. `netpeer serve --script ping|burst|log|silent` listens on a loopback port the system picks and prints `port N`. It answers only guest frames (ARP, ICMP echo, and the UDP burst), logs as §6.4 says, and prints `peer: closed after N frames` when the guest ends. DHCP and DNS are left to A4.
- **The runner's net path.** It is additive:
  - a `net` case key and `expect_peer`;
  - one peer per case, built once per profile and added to `HOSTED_TESTS`;
  - QEMU started with `-S` and QMP on a socketpair, given `cont` once `NETDEV_STREAM_CONNECTED` arrives, or right away if the netdev already reads connected;
  - the peer's log compared line by line, and a peer exiting nonzero fails the case.
- **`tests/virtio-probe`** reads the identity registers. `virtio_probe` and `virtio_probe_empty` run on riscv32 and the flat profile.

**Choices beyond the design:**
- §7.3 gives no expected text for the probe, so the probe's output line is the implementer's own.
- Each case has an image file of its own name, because the runner names the ELF after the case.

**Mutants:** 61 in netpeer, all red. The runner and board mutants are red too: the base moved, the row removed, `force-legacy` left out, `device = "none"` ignored, no `cont`, the wrong `net_bus`, and the peer's lines.

**Not pinned here, named:** the connected wait and `-S` (no frame is sent yet), `props` and `legacy`, and the rows' line and len. A3-4's cases are where each gets exercised.

**Runs:** `make sos-test` 1446, and netpeer's 3 hosted files.
