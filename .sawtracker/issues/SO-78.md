## Description

## Scope

The root image for the box: it collects its boot handles, launches the GPIO
and PWM drivers and a controller task, and the controller turns the switch
back off whenever it is turned on.

- The controller waits on the switch through the GPIO driver, commands the
  servos through the PWM driver, and uses a Timer for the arm's travel and for
  debouncing.
- A second simple task runs beside it (a heartbeat on the console or an LED),
  so the box shows more than one process sharing the machine.
- The motion sequence is data in the controller, so a new behaviour needs no
  driver change.
