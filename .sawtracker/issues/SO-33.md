## The changes

1. **`sawlang.pin`:** `version = "0.21.0"` and `sha =
   "a79ea78c58b1188eb1f15eb8ddbc8f61273a48c7"` (the commit). Change both
   lines together; update the comment above them only if it is now false.
2. **`tools/toolchain.py`:** replace it verbatim with sawlang v0.21.0's
   `tools/toolchain.py`. sawos's copy recognises a checkout by
   `sawc/sawc.py`, which v0.18.0 deleted. The file travels verbatim between
   the two repos: don't edit it.
3. **`tools/sos_runner.py`:**
   - `_build_blade` adds `--module-path blade=<root>/blade/src`, because
     Blade is a multi-module package.
   - The `task_dump` / `task_dump_empty` expectation strings carry the
     `taskdump.saw:NN` / `taskdump_empty.saw:NN` line numbers. Update them
     to the new lines after change 7, and check each against the file.
4. **`chars()` → `scalars()`:** 8 sites, plus `sosrt.ascii_byte` now takes a
   `Scalar` and calls `.value()` (`rt/common/src/lib.saw`). The sites are in
   `hal/arm64/kernel/lib.saw`, `kernel/core/diag.saw`,
   `kernel/sysapi/src/system.saw`, four UART test programs and
   `tests/uartproto/src/lib.saw`.
5. **`kernel/core/slab.saw` `Slab.[]`:** `(&var self, i: Int) unsafe borrows
   -> &var T`.
   - **First try it without `@synthesize(shared)`** (SL-956 may make it
     unnecessary). If the build then reports exclusive-window errors on
     reads, add `@synthesize(shared)` back. Either way, report how many
     errors, of which kind and at which shapes. That's useful sawlang
     feedback.
   - Rewrite that accessor's doc comment to say what it does and why reads
     stay shared (or why `&var` is safe without it), with no design or issue
     references.
6. **`rt/common/src/lib.saw`:**
   - `__saw_rt_write` returns `Int` (0).
   - Add `__saw_rt_write_line(parts, count) -> Int`: it writes `count`
     `{ptr, len}` pairs at **the target's word size**, then a newline.
   - Add `__saw_rt_last_raw_code() -> Int` returning 0: SOS has no errno.
   - Replace the string-literal-as-pointer at the panic path with
     `.c_string()!`.
   - Check every signature against v0.21.0's `runtime/ABI.md`. The build
     checks the seams, so a wrong one fails loudly.
7. **`tests/taskdump.saw` and `tests/taskdump_empty.saw`** (the
   `--runtime-provider` cases):
   - Port `reactor_create`, `reactor_register` and `reactor_poll` to their
     current signatures.
   - Add `thread_executor` / `set_thread_executor` (one `unsafe static var`
     word).
   - Add `output_lock` / `output_unlock` as no-ops.
   - Add `write_error`, which writes to the console.
   - `reactor_register` returns `-16` (never 0): SOS has no reactor, and
     ABI.md's portable tag table maps ENOSYS to tag 16, `Other`. Say so in a
     one-line comment.
8. **`hal/arm64/kernel/lib.saw`, two shifts:** `(1 as UInt32) << (...)`.
9. **`tests/thread-preempt/src/main.saw`:** split the one-line catch body
   across lines in the tree's guard shape.
10. **Anything else v0.21.0 refuses** that the v0.20.0 survey didn't hit: fix
    it minimally, and list it.
