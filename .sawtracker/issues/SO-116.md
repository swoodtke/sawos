## Description

**Ignore `.toolchains/` (user, Nov 15: "add .toolchains to .gitignore").**

Fetched sawlang checkouts for agents live at the repository's root in `.toolchains/<sha>/`, outside `.claude/`: the runner's `.sawlang` link to a checkout under `.claude/` was treated as a link to a sensitive file and asked the user for approval on every touch. The directory was kept out of git by a local exclude only; this puts it in `.gitignore`.
