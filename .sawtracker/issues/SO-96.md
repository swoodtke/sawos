## Description

**User ruling, Nov 13.** Drivers get a top-level `drivers/` directory ("there will be more drivers over time"), and the existing ones move now ("so we are ready to add the new drivers").

**The change: a move and nothing else.** No behaviour, console text, package name or image changes.

What moves, by `git mv`, keeping each directory and package name:
- `tests/svc-uart-ns16550` and `tests/svc-uart-pl011`, the UART service drivers;
- `tests/uartproto`, the protocol library a driver and its clients compile against.

What stays in `tests/`: the launchers and clients that exercise them (`uart-service`, `uart-cancel`, `svc-client`, `driver-child`), and the echo programs (`uart-echo-*`, `child-echo-*`), which are cases about an interrupt and a window, not drivers anyone serves from.

What follows from the move:
- every path that named the old place: `uartproto` dependencies in the packages left in `tests/` (`../../drivers/uartproto`), each moved package's own relative paths (check each still resolves from its new place), and any `Saw.lock` that records a path, regenerated by the tool that writes it and not by hand;
- `tools/sos_runner.py`: a `DRIVERS_DIR` beside `TESTS_DIR`, the package constants, and anything that walks `tests/` for packages or build outputs and must now walk `drivers/` too;
- `Makefile`, `.gitignore`, `spec.md` and any `ABI.md` or `README.md` naming the old paths;
- comments that are no longer true: `uartproto`'s `Saw.toml` says the protocol lives "in `tests/`", and the drivers' headers call other packages "beside it". Say what is true now, in the comment rules' terms;
- `CLAUDE.md`'s repo map gets a `drivers/` row: userspace device drivers and the protocol packages their clients share, each an ordinary package like those in `tests/`.

**Acceptance.**
- `git diff -M --stat` against the base shows the three directories as renames; a moved file's content changes only where a path or a now-false comment required it.
- No file under the repository names `tests/svc-uart-ns16550`, `tests/svc-uart-pl011` or `tests/uartproto` (outside `.sawtracker/`, which nobody edits).
- The gate (`make sos-test sos-smoke-esp32c3 sos-smoke-esp32s3`) prints the same totals as the base, and the runner's report for the cases that build these packages is the same text before and after on every profile, image sizes included.
- `python3 .claude/lead/runner_dupkeys.py tools/sos_runner.py` (the lead's copy, by absolute path) reports no duplicate key and the same count of named cases as the base.
