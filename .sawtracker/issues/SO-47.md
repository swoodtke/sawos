## Description

sawlang's LANGUAGE_SPEC.md (Profiles, v0.21.0) says that on riscv32 without `+a` the environment supplies **five** word atomics:
- `__atomic_load_4`
- `__atomic_store_4`
- `__atomic_fetch_add_4`
- `__atomic_fetch_sub_4`
- `__atomic_compare_exchange_4`

`rt/common_c/support.c` defines the first four. Nothing in the tree references `__atomic_compare_exchange_4` today, so the ESP32-C3 build links. A C3 build that compiles a compare-and-swap (`Atomic<Int>` CAS, or an `Arc` path that uses one) would fail to link.

**Fix:** add `__atomic_compare_exchange_4` in the same interrupt-masked style, with a C3 case that exercises it so it isn't dead code.

Found while ruling SO-34.

Correction to the description: `support.c`'s word atomics are plain read-modify-write with no masking of their own. They are sound in the kernel, which runs with interrupts masked, and in a user process only while nothing preempts it. A `__atomic_compare_exchange_4` should follow the same model and say so; it should not be written in an "interrupt-masked style".

**Lead review, SO-47.p1.**

**Probe on the unfixed tree.** The new C3 package `c3-cas` (`Atomic<Int>.compare_exchange`) fails to link: `undefined symbol: __atomic_compare_exchange_4`, from `std/prelude.saw:351`.

**The fix.** `__atomic_compare_exchange_4(volatile void *ptr, void *expected, u32 desired, int success_order, int failure_order)` sits beside the other four, with the same plain read-modify-write model. On a mismatch it writes the current value to `*expected` and returns 0.
- My brief gave a 6-argument form with `bool weak`. That is the generic `__atomic_compare_exchange` builtin, not the sized libcall.
- The implementer checked the emitted call against the built ELF: a0 = ptr, a1 = &expected, a2 = desired, a3 = a4 = 5 (seq_cst/seq_cst), and the IR is `cmpxchg … seq_cst seq_cst`. So 5 arguments is correct.

**The case.** `cas` asserts a successful 5→9 swap and a failed 5→7 swap that leaves 9. `llvm-nm` shows `T __atomic_compare_exchange_4`.

**Runs**
- C3 smoke 4/4. The other three flash sizes are unchanged.
- Gate subset 9/9 on three profiles.
