## Description

**A process's declaration names the System rights it gets.** Today the stock root gives every child one fixed System sibling, `Debug | ProcessSelf | ClockGet | Transfer` (spec §12's launch convention; `root/src/main.saw`'s `CHILD_SYSTEM`). `Shutdown`, process creation and the rest are already withheld. The owner (Nov 17): with a console driver serving `uartproto` (SO-137), only that driver needs `Debug`; every other process should run without it, so restrict what each process gets.

**Build:** a process's `system` record in `process.toml` may name the rights it needs (by `SystemRight`'s names, e.g. `rights = ["debug", "clock-get"]`), held to a set the stock root may give (the convention's four; anything else refused by name in the declaration reader, since a child granted `Shutdown` or process creation is root's choice, not a declaration's); the plan carries each child's set as names (no rights word in the plan, as now); root mints each child's sibling with exactly its set. A record that names none keeps today's four, so nothing that exists changes. spec §12's launch convention says the rule (a spec change, the owner's direction given above). The console driver (SO-137) declares `debug`; the box's processes (SO-78) declare none of it.

**Cases:** a child declaring a subset prints each `SystemRight` by name, as `stock_root`'s children do, and holds the set; a child without `Debug` whose print is refused (the status it gets, held); a declaration naming a right root may not give refused by name; a record naming none unchanged (every existing transcript). The review standard: every check and refusal red when removed or inverted; list the mutants.

Also, since SO-124's design: a process's panic no longer needs `Debug` (the coming handle-free `PANIC_OP` carries its text), and a `print` refused for want of `Debug` is dropped by `sos.rt` rather than faulting once SO-124's unit lands; until then a `print` without `Debug` is today's `AccessDenied` fault, which this unit's case holds.
