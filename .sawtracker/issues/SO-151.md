**Networking A2: the Saw stack's first layer, hosted.** Unit A2 of the networking design (`SO:networking`, SO-103 §10). The owner ruled on Nov 24 that TCP/IP is written in Saw, UDP first.

A new library package, `drivers/netstack` (or a name the design's §5 suggests), with the stack's first layer as pure functions and state machines over byte buffers, with no `sos` dependency, so `blade test` runs it on the host and `HOSTED_TESTS` lists it:
- **Ethernet II framing.** Parse and build, the MAC filter (ours, broadcast; multicast off), EtherType dispatch.
- **ARP (RFC 826) for IPv4 over Ethernet.**
  - A cache with a fixed capacity and entry ageing, driven by a caller-supplied monotonic time (no clock inside).
  - Request and reply; answering requests for our address; a pending-resolution queue of bounded depth that drops, counted, when full.
  - Gratuitous ARP on address change.
- **IPv4 (RFC 791).**
  - Header parse and build with the checksum.
  - Refuses, counted:
    - a bad version or IHL;
    - a total length past the frame;
    - a bad checksum;
    - fragments (no reassembly in this unit: MF set or a nonzero offset is dropped and counted, and the docs say so);
    - an unknown protocol.
  - TTL on send. A single interface with address, netmask and gateway: next hop is the gateway off-link.
- **ICMP (RFC 792).** Echo reply to an echo request. Destination unreachable (port) for a UDP datagram to a closed port, rate-limited by a caller-supplied time. Other types are counted and dropped.
- **UDP (RFC 768).**
  - Parse and build with the pseudo-header checksum (zero checksum accepted on receive, always computed on send).
  - A bounded port table binding ports to small socket ids; ephemeral ports from 49152–65535.

**Rule 5.2 applies at the frame boundary:** the layer parses from a private copy of the headers, every length is checked against what was received, and a malformed frame is a counted drop, never a panic. The interface the layer gives upward (deliver a datagram to socket id N, send a datagram from id N to addr:port) and downward (a frame to transmit, a frame received) is plain data, so A3's virtio-net driver and A6's sockproto server can drive it.

**Tests.**
- Golden frames for each protocol, built by hand from the RFCs' layouts. No captures from outside the repo.
- Round trips; every refusal by name and counter.
- ARP resolution end to end between two stack instances wired back to back in a test: ping and UDP echo between them, all hosted.
- Every check has a case that goes red when it is removed or inverted; list the mutants.
