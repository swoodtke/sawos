## Scope

User ruling (Nov 8 2026): source comments say how the code works and what must stay true. They carry no design/unit/milestone numbers, issue references (SL-, DF-, sawlang#), rulings, dates, or "used to / now / HAS LANDED" narration; that history lives in `designs/` and git. A "why" stays only when it is non-obvious and prevents a real mistake. `spec.md §N` pointers stay. Sentence case, not ALL-CAPS emphasis. Comment prose wraps at 80 columns.

Every unit changes COMMENTS ONLY: a comment-stripped comparison of each file against its base must be identical. Implementation is by Sonnet subagents from a lead-written brief (the unit's description).
