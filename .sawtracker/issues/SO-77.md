## Description

## Scope

Userspace drivers for the two devices the box uses, each a process holding
only its own window.

- **Device rows:** the GPIO and LEDC windows in the board's region table, so
  they reach root as `IoMemory` and root hands each to its driver.
- **GPIO driver:** configure a pin as an input with a pull, read it, and wake
  on its edge through the GPIO interrupt line; configure a pin as an output.
- **PWM driver:** LEDC at a servo's 50 Hz frame with the pulse width as the
  request, one channel per servo.
- Each serves a pipe protocol, as `tests/svc-uart-ns16550` does for a UART.
- Register blocks are typed structs over the mapped window, with volatile
  accessors.

Under QEMU the GPIO driver is checked as far as the emulator models the
device, and the PWM driver as register writes only, because the emulator has
no LEDC. The real check is on the board.

## Needs the user

The pins: the switch, each servo's signal, and how the servos are powered.
