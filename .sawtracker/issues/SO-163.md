**Networking A3-2: `drivers/virtio`, the hosted virtio library.**

The design is `SO:virtio-net` revision 4, §2, §4 and §7.4, with the owner's rulings of Nov 25. This unit is §8's A3-2:
- the MMIO transport, version 2;
- feature negotiation;
- split queues, with the device's values checked;
- the failure classes;
- the memory lifecycle's order: pin before any address reaches the device, and unpin only after a confirmed reset;
- tests against a fake device (§7.4).

It is a new package. It is hosted, so it needs no QEMU, and it joins `HOSTED_TESTS`.
