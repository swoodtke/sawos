## Description

## Scope

SOS boots on the emulated ESP32-S3: an Xtensa architecture HAL and the S3
board, on the `Flat` protection tier, with a gating smoke.

- **The architecture half:** vectors and trap entry, the trap frame as the
  thread context, the `syscall` stub for user images, `resume_frame`, and the
  leaves the arch-free kernel calls through `hal`. `hal/riscv32-common` is the
  model for the split, and `hal/riscv32-flat` for the tier.
- **The board half:** boot, the console, the timer seam (`timer_now_ns`,
  `timer_set_deadline_ns`), the interrupt controller, the memory map and the
  linker scripts for the kernel, root and a child.
- **The harness:** `--board esp32s3` in `tools/sos_runner.py`, a
  `make sos-smoke-esp32s3` target, and the server's `tests.json`.
- **Smoke cases:** boot to the banner; a Timer fire reaches a process; a
  child is created, exchanges a pipe message and exits; two threads are
  preempted by the tick harness.

Every board fact comes from `hal/xtensa-esp32s3/ABI.md` (the probe unit).

### 75a: the architecture's assembly and C (Sonnet)

Lift SO-73's stub into `hal/xtensa-common/kernel/`: the vectors, one trap
entry that saves the frame `ABI.md` lists and calls `ktrap`, the restore
path, and `resume_frame`; `sink.c` for the special-register leaves; and
`hal/xtensa-common/user/syscall.c`, the `syscall` stub user images link.
`hal/riscv32-common/kernel/trap.S`, `sink.c` and `user/syscall.c` are the
model for what each file owes the kernel. The frame is the thread context:
a switch is `ktrap` returning a different frame (spec §7).

### 75b: the `hal` facade in Saw, flat tier (Opus if the seam needs judgment)

`hal/xtensa-esp32s3/kernel/lib.saw`. Its public surface is the list the
arch-free kernel imports; `hal/riscv32-esp32c3/kernel/lib.saw` is the
checklist, function by function, and `hal/riscv32-flat/kernel/lib.saw` shows
the protection seam answered for a tier that cannot deny (`prot_isolated()`
false, the `prot_*` calls recording nothing the hardware enforces). The
console, the timer seam (`timer_now_ns`, `timer_set_deadline_ns`), the
interrupt controller and the exit path come from `ABI.md`.

### 75c: the board, the harness and the smoke (Sonnet)

**Lead, Nov 12: facts from the sawlang sweep (SL-1063), for these notes.**
- **call0** is the absence of the `windowed` feature. In C the spelling is
  `-Xclang -target-feature -Xclang -windowed`; Espressif's clang has no
  `-mabi`. Every SOS image is call0 and builds with `-fp`.
- **No call0 multilib exists:** libgcc, libclang_rt and the ROM's helpers are
  windowed, so no SOS image may call or link them. 64-bit divide comes from
  std's own helpers.
- **The trap frame:** compiled Saw code touches a0 to a15, SAR and SCOMPARE1.
  Save those, plus LBEG, LEND and LCOUNT until the compiler side rules out
  the `loop` instruction.
- **Word atomics are inline** (`wsr scompare1` + `s32c1i`), so the HAL sets
  ATOMCTL at boot. SO-73 probes the value.
- **Tools:** Homebrew's `ld.lld` can't link Xtensa; use the `ld.lld` beside
  Espressif's clang or `xtensa-esp-elf-ld`. Use the QEMU under
  `~/.espressif`, not the one on `PATH`.
- **Image format:** `SosimgArch` Xtensa = 3.
- **Triple:** the sweep recommends `xtensa-esp-unknown-elf` with the CPU
  named; the user decides.
