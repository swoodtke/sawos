## Description

`tests/thread-preempt/src/main.saw:157` has two statements on one line with no `;` between them:

```saw
let cost = try proc.stats() catch { let _ = proc.exit(0)  return }
```

GRAMMAR.md refuses this under `syntax.rule.statement-separator`: two statements on one line need a `;`. The self-hosted parser (sawc2) and the grammar's reference recognizer both refuse it. Only the frozen Python parser's leniency accepts it.

It is the one file of sawos's 205 that sawc2 doesn't parse, and SL-398's acceptance item 1 names sawos in the parser's acceptance corpus (SL-398 c7).

**Fix:** write `let _ = proc.exit(0); return` inside the catch block, or put each statement on its own line. Behaviour is unchanged, and the fix goes through sawos's own gate (`make sos-test`).
