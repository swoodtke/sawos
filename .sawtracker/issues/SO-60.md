## The change

1. **Exports** (`kernel/sysapi/src/lib.saw` ~170–225).
   - Re-export all fifteen rights enums from `sosabi`: `SystemRight`,
     `ProcessRight`, `ThreadRight`, `EventRight`, `WaiterRight`,
     `InterruptRight`, `ClockRight`, `TimerRight`, `MemoryRight`,
     `IoMemoryRight`, `MappingRight`, and the four pipe ones.
   - The comment block today states the opposite rule ("A kind whose handles
     nothing masks has no reason to publish its bits, and each rights enum joins
     this list with the funnel that needs it"). Replace it with the new rule:
     every kind's rights are public, because a holder narrows any handle at a
     mint, a give's keep mask or before a send. Keep the existing per-enum
     examples only where they still say something useful, and keep the "no op
     numbers" point.
   - An open patch, SO-58, adds `public import sosabi.{EventRight}` after
     `MemoryRight`. If it has merged when you fetch, build on it. If not, add
     `EventRight` yourself; the lead resolves the overlap.
2. **Typed `mint(rights:)`** on every wrapper whose kind's default rights carry
   the universal `Mint` bit (check each `*_rights()` in
   `kernel/abi/src/rights.saw`). Today only `Memory`, `System`, `Process` and
   the four pipe wrappers have one; the candidates are `Event`, `Waiter`,
   `Timer`, `Thread`, `Clock`, `IoMemory` and `Mapping`.
   - **Interrupt gets no `mint`:** the spec removes `Mint` from it (one name),
     even though the kernel still carries it today.
   - Copy `Memory.mint(rights:)`'s shape exactly (`memory.saw` ~126): the
     default `ALL_RIGHTS` and `MINT_OP` through `call_value`. Copy its doc
     phrasing too.
   - If a kind's wrapper is shaped differently and can't take that form, stop
     and ask.
3. **Spec:** if §3 or §4 says only some rights enums are public, or lists
   which kinds have a typed `mint`, update it. No issue numbers; 80 columns.

## Tests

One runner case, modelled on the existing mint cases (grep `mint(` in
`tests/`):
- For each newly minted kind, mint a narrowed sibling and show that the
  withheld right is refused (the `AccessDenied` fault ends the process).
- Faults end the process, so either one child per kind or one case per kind;
  pick the cheapest shape that still asserts each.
- At minimum cover `Event` (withhold `Signal`), `Timer` (withhold `Arm`),
  `Waiter` (withhold `Attach`), `Thread` (withhold `Join` or `Control`),
  `IoMemory` and `Mapping` (withhold a map or base right), and `Clock` (withhold
  `ClockGet`).

Approved patch SO-60.p1 (revision 2)

**Air: SO-60.p1 revision 2, approved.** The new typed `mint(rights:)` wrappers can only narrow, and the kernel guarantees it rather than the library. `mint_sibling` gates on the source's `Mint` bit and mints `entry.rights & keep` (dispatch.saw), so a sibling is a subset of its source by construction, and a mask naming a right the source lacks is a no-op. Each wrapper is a direct `call_value(self.handle, MINT_OP, rights, …)` in `Memory.mint`'s shape, with the all-ones default. Interrupt rightly has none, since it has one name.

Each of the seven `mint_narrow_*` cases shows the sibling is live through a kept right (Thread yields, Timer attaches, Waiter reports through the original's attachment, and so on) before the withheld right ends the process with `access denied`. So the denial means the missing bit, not a broken handle. Clock withholds `Read`, since `ClockGet` is a SystemRight.

Revision 2 against revision 1 is test comments only. The §3 paragraph matches the code, and no added line is over 80.
