## Description

## Scope

Add `.claude/` to `.gitignore`.

The directory holds machine-local Claude Code state: the sawtracker token (`.claude/sawtracker.token`) and the git worktrees that implementing subagents run in (`.claude/worktrees/`). None of it belongs in the repository. The token in particular must never be committed.

## Acceptance

- [ ] `.gitignore` lists `.claude/`
- [ ] `git status` on a checkout with a token and an active worktree shows nothing under `.claude/`
