## Ruling (user, Nov 12)

The GitHub builds are disabled. The sawtracker server's gate is the only
validation, and Linux is not a supported build host for now.

- Delete `.github/workflows/ci.yml`. Nothing else in the tree names it.
- README and CLAUDE.md already describe the sawtracker gate; check that
  neither promises a GitHub or Linux run.

The cold fetch at the pin, the original subject of this issue, runs on every
gate: the server resolves through step 3 and its transcript header reads
`sawlang: fetch`, at the pinned sha.

## Acceptance
